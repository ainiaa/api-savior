# PRD：P0 安全与请求参数生成线程加固

## 1. 背景与目标

### 1.1 背景

插件当前的 GitHub 异常上报实现包含可提取的内置认证凭据，并会将完整 JVM 系统属性随异常发送到远端；这不满足插件的最小权限和敏感信息保护要求。与此同时，“Generate Api/RPC Param Doc”直接在 Action 调用线程执行 PSI 深度解析，绕过已用于接口文档生成的后台任务和 `GenerationSession`，在大型 DTO 或新版 IDEA 线程断言下存在卡顿、配置未初始化和访问违规风险。

### 1.2 目标

- 移除插件发行物中的内置远端认证凭据，并停止自动上传诊断信息。
- 将请求参数文档生成接入统一的后台生成会话，确保 PSI 访问、配置初始化、取消和清理路径一致。
- 保持现有右键入口、复制结果、参数 Markdown 与 REST/RPC 输出格式不变。

## 2. 目标用户

| 用户角色 | 描述 | 核心需求 |
|----------|------|----------|
| 插件使用者 | 在 IDEA 中生成接口或请求参数文档的开发者 | 不泄露本机信息，生成复杂 DTO 时界面仍可响应。 |
| 插件维护者 | 发布和维护插件的开发者 | 不在源码或 ZIP 中承担长期凭据泄露风险，故障可由用户主动、可控地反馈。 |

## 3. 功能需求

### 3.1 功能列表

| 编号 | 功能 | 优先级 | 描述 | 验收标准 |
|------|------|--------|------|----------|
| FR-01 | 安全诊断降级 | P0 | 删除内置 GitHub 认证与自动远端 Issue 创建；插件错误仍由 IDEA 显示，用户可自行选择手工反馈。 | 源码与插件 ZIP 不含认证令牌；异常上报路径不再通过 GitHub API 发送异常或系统属性。 |
| FR-02 | 最小化诊断数据 | P0 | 不收集或上传完整 JVM 系统属性、环境相关属性和用户补充信息。 | 诊断实现不存在 `System.getProperties()` 的远端请求组装；无自动 HTTP 上报。 |
| FR-03 | 请求参数后台生成 | P0 | REST/RPC 请求参数文档在可取消的后台任务中生成，PSI 解析仅在 Read Action 内执行。 | 复杂对象解析不直接阻塞 Action 调用线程；取消异常继续交由 IDEA 处理。 |
| FR-04 | 生成会话一致性 | P0 | 请求参数文档复用 `GenerationSession`，按当前文件初始化配置并在完成、异常、取消时释放状态。 | 自定义参数模板配置可生效；配置、泛型、字段序号与 IP 状态不会遗留至下一次生成。 |

### 3.2 用户故事

- 作为插件使用者，我希望异常不会被插件自动上传，以便控制我的本机与代码上下文信息。
- 作为插件使用者，我希望生成深层请求参数时 IDE 仍可交互，以便继续编辑和取消任务。
- 作为项目维护者，我希望请求参数生成遵循与接口文档相同的会话规则，以便避免新版 IDEA 的线程访问异常和配置串扰。

### 3.3 用例分析

#### UC-001：用户生成 REST/RPC 请求参数文档

- **参与者：** 插件使用者。
- **前置条件：** 在 Java Bean 上打开右键菜单；项目可包含自定义 `docer-config.properties`。
- **主要流程：**
  1. 用户触发请求参数文档 Action。
  2. 插件保存 PSI 智能指针并启动可取消后台任务。
  3. 后台会话按当前文件加载配置，在 Read Action 中解析结构、示例和模板文本。
  4. 任务成功后在 UI 线程更新剪贴板并展示参数说明。
- **备选流程：** 用户取消任务或目标 PSI 已失效时，不更新剪贴板，不遗留线程状态。
- **后置条件：** 生成结果与现有格式一致。

#### UC-002：用户提交 IDEA 插件错误报告

- **参与者：** 插件使用者。
- **主要流程：**
  1. IDEA 展示插件错误信息。
  2. 插件不携带内置凭据创建远端 Issue，也不上传系统属性。
  3. 用户如需反馈，可通过公开仓库页面自行决定提交内容。
- **后置条件：** 插件发行物中不存在可用于远端写入的内置凭据。

## 4. 非功能需求

- **性能：** 请求参数 Action 的耗时 PSI 解析必须在后台进度任务执行；UI 线程仅进行任务启动和结果呈现。
- **安全：** 不硬编码、混淆或打包任何远端写入凭据；异常上报默认不出站传输诊断数据。
- **可用性：** 保持 Java 11 字节码、IDEA 2021.1.1 至当前声明版本的兼容范围；取消操作不显示为普通错误。
- **可维护性：** 不新增第三方依赖；复用现有 `GenerationSession`、`AbstractOnRightClickSavior` 和 IDEA 平台能力。

## 5. UI/UX 需求

- 保持现有右键菜单名称、剪贴板提示与参数说明对话框。
- 安全降级不新增登录、令牌输入或配置页面；远端反馈由用户在浏览器中自主完成。
