# 测试计划：P0 安全与请求参数生成线程加固

## 1. 测试范围

覆盖自定义远端错误上报从插件描述符和运行时类路径中移除，以及请求参数文档生成必须复用通用后台结果执行器的结构性回归。PSI 深度解析的真实线程语义由两个支持版本的 IDEA 安装包手工验收。
